# Manual técnico da Tone Market

Este diretório concentra a documentação operacional do projeto. A aplicação foi preservada em sua estrutura React, Express, tRPC e Drizzle, enquanto os guias abaixo separam responsabilidades de desenvolvimento, banco, mídia, autenticação e publicação.

| Documento | Uso |
| --- | --- |
| [`01-START-HERE.md`](./01-START-HERE.md) | Primeiro acesso no VS Code e sequência de inicialização local. |
| [`02-ARCHITECTURE.md`](./02-ARCHITECTURE.md) | Mapa técnico de frontend, backend, rotas, banco e ativos. |
| [`03-EXTERNALIZATION-CHECKLIST.md`](./03-EXTERNALIZATION-CHECKLIST.md) | Lista de adaptação obrigatória para sair do ambiente original. |
| [`04-OPERATIONS-RUNBOOK.md`](./04-OPERATIONS-RUNBOOK.md) | Rotina para desenvolvimento, testes, banco, build e manutenção. |
| [`05-ADMIN-ACCESS.md`](./05-ADMIN-ACCESS.md) | Conta administrativa definida e ativação segura após o primeiro login externo. |

Os guias específicos existentes permanecem na raiz do projeto para acesso direto: `HOSTINGER_DEPLOYMENT.md`, `POSTGRESQL_SETUP.md`, `EXTERNAL_DEPLOYMENT.md`, `ASSET_MANIFEST.md` e `database/SEEDING.md`.
